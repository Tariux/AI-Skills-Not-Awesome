# "Cannot Verify From Diff" Items

The task reviewer may report "⚠️ Cannot verify from diff" — requirements in unchanged code or spanning tasks.

These do not block the rest of the review, but you must resolve each yourself before marking the task complete (you hold the plan and cross-task context the reviewer lacks).

If you confirm an item is a real gap, treat it as a failed spec review — it enters the fix loop with other findings.
